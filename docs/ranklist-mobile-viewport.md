# 榜单移动端初始缩放

榜单合集、榜单详情和实时榜单在手机浏览器中以 0.5× 打开，使用站点现有的最小缩放比例。用户可以用双指放大。榜单之间的站内切换沿用当前缩放，离开榜单路由时恢复站点默认的 1×。

## 客户端路由

客户端入口在 Vue Router 启动前注册路由钩子。初次进入和后续成功导航都由相同的钩子处理，在首次揭示页面前调整 viewport。触发条件是主要输入为触控且不支持悬停，并且设备的短边不超过 768 CSS 像素。窄桌面窗口仍按既有的宽度断点排版，初始比例是 1×。

服务端始终使用同一份 viewport 标记。SSR、缓存命中和 CSR 都由浏览器根据实际设备与路由设定初始比例，SSR 缓存键沿用 URL 和语言。

## 窄屏布局

当初始比例为 0.5× 时，390px 的手机浏览器会创建 780px 宽的布局视口。榜单工具栏、合集侧栏及站点内边距补充了设备宽度断点，以保留窄屏控件。合集和实时榜单等需要在 JavaScript 中读取宽度时，会在榜单缩放期间以设备宽度约束布局视口宽度。表格继续使用文档的滚动区域，窄屏表头随页面纵向滚动吸顶。

## 验证

使用 Chromium 和 WebKit 在手机视口验证三个入口。Playwright 回归覆盖 SSR 缓存复用、纯客户端渲染、刷新、站内切换、侧栏和表头吸顶，以及 Chromium 双指放大再缩小。
